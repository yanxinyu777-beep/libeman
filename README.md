# BookVault

BookVault 是一个本地藏书管理工具，用来扫描多个文件夹中的电子书，建立 SQLite 索引，按书名、作者、标签、出版社、ISBN 和格式进行搜索筛选，并支持安全的批量操作。

## 功能

- 支持 PDF、EPUB、MOBI、AZW/AZW3、TXT、MD、DOCX、RTF、DOC 等常见文本/电子书格式。
- 后台扫描指定文件夹，自动识别书籍文件并提取轻量元数据。
- 读取同目录 OPF 元数据和 JPG/PNG/WebP 封面。
- 自动生成常见书籍标签，也可以手动给选中的书批量加标签。
- 支持按标签、格式、关键词、状态组合筛选。
- 支持选择本页、选择当前筛选结果、跨页批量操作。
- 扫描时先建立本地索引，再自动启动后台任务补齐书籍简介和豆瓣评分；中文书籍优先使用豆瓣信息。
- 后台任务进度持久化；服务重启后会保留历史并标记中断任务。
- 支持批量发送副本到桌面 `BookVault_Copies`。
- 支持安全删除：文件会移动到桌面 `BookVault_Quarantine`，并生成 `manifest.json`，不会直接永久删除。

## 启动

```powershell
cd C:\Users\Administrator\Documents\aicoding\bookvault
python .\app.py --host 127.0.0.1 --port 8765
```

打开：

```text
http://127.0.0.1:8765
```

## 数据保存

书库记录保存在 `data/bookvault.sqlite3`，每条记录都会保留源文件完整路径，用来维持“记录 -> 原文件”的对应关系。程序启动不会清空数据库；再次打开后会直接读取已有记录。

程序每天启动时会在 `data/backups` 下保留一份 SQLite 备份。若上次关闭时联网补齐还没跑完，下次启动会自动恢复未完成的补齐任务，不需要重新扫描源文件夹。

## 可选依赖

程序没有强制第三方依赖。若希望读取 PDF 标题和前几页文本，可安装：

```powershell
python -m pip install -r requirements.txt
```

## 使用建议

第一次扫描 8 万本书时，程序会先把可识别文件快速写入本地数据库，每本书都会先显示本地生成的简短简介；豆瓣评分和联网简介会在后台按顺序补齐。这样即使网络慢、豆瓣限流或某个文件损坏，也不会阻塞整个本地索引。

重复扫描同一目录时，大小和修改时间未变化的文件会跳过本地解析；已成功查过或确认未找到评分的书也会跳过联网查询。查询失败的记录会在 24 小时后允许重试。

豆瓣网页偶尔会限流或匹配不到条目；这类书会保留本地简介和“未找到/查询失败”的评分状态，不影响后续筛选和批量操作。

## 健康检查

修改代码或正式扫描大书库前，可以运行：

```powershell
python .\tools\health_check.py --live-url http://127.0.0.1:8765
```

它会检查前端表头、简介长度、“未分类”残留、豆瓣评分显示、大批量 ID 查询和当前 API 状态。
默认还会校验 active 记录对应的源文件是否仍然存在；如果只想快速检查接口，可加 `--skip-source-check`。
